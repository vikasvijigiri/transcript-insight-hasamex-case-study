# Phase 1: Backend — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the transcript-serving endpoint and citation offset the frontend redesign needs, then harden the backend per the security/best-practices audits — all before any frontend work starts, since Phase 2 depends on this phase's API surface.

**Architecture:** No changes to grounding/citation-resolution logic. Two additive API changes (new endpoint, new schema field) plus five independent hardening changes (dead-endpoint removal, rate limiting, host-header protection, docs gating, dependency-manager migration). Each task is independently testable and committable.

**Tech Stack:** FastAPI, Pydantic v2, pytest, `slowapi` (new), `uv` (new, replaces pip+requirements.txt).

**Spec:** `docs/superpowers/specs/2026-09-22-frontend-redesign-design.md` §7 (all of §7a/7b/7c). Full reasoning for every decision below lives in `design/BACKEND_BEST_PRACTICES_CHECKLIST.md` and `design/SECURITY_CHECKLIST.md` — this plan implements those decisions, it doesn't re-argue them.

## Global Constraints

- No behavior change to `resolve_citations` or `verify_quote` — every task here either adds new data to what's already returned, adds a new route, or adds middleware. Nothing here changes how a citation is resolved or verified.
- Every task must leave `pytest -q`, `ruff check app/ tests/ evals/`, `ruff format --check app/ tests/ evals/`, and `mypy app/` green before moving to the next task.
- No live API calls in `pytest` — `fake_provider`/`conftest.py`'s existing mocking pattern is followed for every new test.
- Windows dev environment (per this repo's `CLAUDE.md`) — commands given for `.venv/Scripts/activate`-style activation; adjust silently for POSIX shells if the executor is on one.

```python
def resolve_citations(raw_citations: list[RawCitation], doc_order: list[dict]) -> list[Citation]:
    resolved: list[Citation] = []
    for rc in raw_citations:
        if rc.document_index >= len(doc_order):
            continue
        expert = doc_order[rc.document_index]
        transcript = load_transcript(expert["id"], expert["file"])
        if not verify_quote(rc.cited_text, transcript.raw_text):
            continue
        resolved.append(
            Citation(
                expert_id=expert["id"],
                expert_name=expert["name"],
                quote=rc.cited_text.strip(),
                timestamp=transcript.timestamp_for_offset(rc.start_char_index),
                start_char=rc.start_char_index,
            )
        )
    return resolved
```

```python
def expert_transcript(expert_id: str):
    try:
        expert = get_expert(expert_id)
    except KeyError:
        raise HTTPException(404, f"Unknown expert '{expert_id}'") from None

    transcript = load_transcript(expert["id"], expert["file"])

        expert_id=expert_id,
        raw_text=transcript.raw_text,
        segments=[

            for s in transcript.segments
```
